# 🐍 Neon Snake Game

Game Snake klasik dengan tampilan neon modern menggunakan HTML, CSS, dan JavaScript Vanilla.

## ✨ Features

- 🎮 Gameplay Snake klasik
- 🌈 Neon modern UI
- 📱 Mobile touch controls
- ⌨️ Keyboard support (WASD + Arrow Keys)
- 🏆 High Score menggunakan Local Storage
- 🔄 Restart game system
- 🧱 Screen wrap movement
- ⚡ Smooth animation dengan Canvas API

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

---

## 🎯 Controls

### Keyboard
| Key | Action |
|------|--------|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |

### Mobile
Gunakan tombol kontrol di layar untuk menggerakkan ular.

---

## 🚀 Getting Started

1. Clone repository ini

```bash
git clone https://github.com/USERNAME/neon-snake-game.git
```

2. Buka folder project

```bash
cd neon-snake-game
```

3. Jalankan file `index.html`
